# 电动车充电里程记录

一个移动端优先的本地 Web App。每次充电前输入电动车仪表盘上的总里程，应用会保存记录，并自动计算两次记录之间跑了多少公里。

## 功能

- iPhone 上直接打开 `index.html` 单机使用
- 保存每次充电前的总里程
- 自动计算每次充电间隔里程
- 展示平均、最长、最短续航
- 绘制续航趋势图
- 删除单条记录或清空全部记录
- 导出 / 导入 JSON 备份
- 电脑本地服务模式可保存到 `data.json`

## iPhone 单机使用

优先把 `电动车里程单文件版.html` 传到 iPhone 的“文件”App 里，然后打开它。这个文件已经包含页面、样式和脚本，不需要再传 `styles.css` 或 `app.js`。

页面会使用当前浏览器的本机存储保存记录，刷新页面、关闭再打开都还在。

注意：iPhone 浏览器不允许一个普通 HTML 页面静默写入同文件夹里的 `data.json`，这是系统和浏览器的安全限制。所以手机单机模式使用浏览器本机存储，并提供 JSON 导出 / 导入备份。

建议偶尔点右上角向下箭头导出 JSON 备份。换手机、换浏览器或清理浏览器数据前，先导出备份；之后用右上角向上箭头导入。

如果关闭页面后数据消失，通常是因为页面开在 GitHub App、微信、飞书等 App 内置浏览器，或开在 Safari 无痕模式。请复制 GitHub Pages 地址，用 Safari 普通标签页打开；也可以在 Safari 里点分享按钮，添加到主屏幕后固定从那里进入。

## 电脑 JSON 模式

如果在电脑上使用，并且想让记录真实写入项目目录下的 `data.json`，启动本地服务：

```bash
node server.js
```

然后打开：

```text
http://localhost:5173/
```

这种模式下数据保存在项目目录下的 `data.json`。
